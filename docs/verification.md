## 应用与兼容

- 旧版 schema v1 数据库覆盖安装后经 Migration1To2 升级为 v2，旧有两笔合成流水仍在，事项字段已补齐。
- 日期字段打开系统 DatePicker，确认后进入 24 小时 TimePicker（小时、分钟），不再使用日期文本框。
- 最近任务验证：冷启动、退后台、连续分享，并附 NEW_TASK / NEW_DOCUMENT / MULTIPLE_TASK 标记，dumpsys 显示仅一个任务（sz=1），分享通过 onNewIntent 复用实例。
- 账单列表仅显示事项、分钟级时间、实际收支金额、渠道，保留月份分组和筛选。
- 新增/编辑渠道与分类使用独立页面，账户、通知监听、商户分类规则、独立统计入口已移除。
- 首页仅保留账单、顶部搜索/筛选/更多和右下角“＋记一笔”，设置位于二级页面，无底部导航或分析占位入口。
- 一次点击进入录入并聚焦金额、弹出数字键盘；只输入金额和分类可保存，空事项保存为分类名。新一笔金额和分类为空，渠道沿用上次手动选择。
- 截图缺失渠道时明确提示“未识别”，不使用手动默认渠道；真实分享核对成功，并验证后台分享仍为单任务。
- 全部分类平铺；旧分类保留 ID 及流水引用，同类型同名用数字后缀区分。启动与恢复均归一化，不改变 schema v2。
- 手动录入中切换系统外观后表单仍保留；系统返回与页面返回均显示未保存修改的放弃确认。
- 320dp 窄屏及 1.5 倍字体下，已实际完成金额输入、滚动选择分类及保存；保存按钮位于键盘上方。
- 筛选面板使用完整展开的底部面板，应用/重置操作固定在底部；筛选后往返设置保留原条件。
- 在已滚动的账单上展开搜索能够滚回搜索框并聚焦；查询及首页滚动状态由根页面保存。
