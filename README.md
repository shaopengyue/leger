# 花钱如流水 · 极简本地记账

首页为账单和右下角“＋记一笔”，点按钮直接进入手动录入。设置收在右上角「更多」中。

账单从最近的月份开始，按月分组连续滚动。每笔左侧显示分类图标，以分类为标题，事项内容和时间显示在下方。每组的月份和当前明细的收支合计会吸顶，下一个月份到达顶部时接替前一组。点月份可以直接跳转，搜索和筛选会同时更新明细和合计。

## 快速录入

点「记一笔」后先选分类、渠道和时间，再点金额打开数字键盘。金额支持加法，实时显示合计。分类和渠道各占一行，左右滑动查看所有启用项，保存后才更新最近使用顺序。

分类和渠道在设置中新增、编辑、停用或移除。移除已被使用的项目时，先选择迁移目标。还没有可用分类时，可以从录入页进入设置添加并返回表单。

分类图标按名称从内置图标中匹配，同分类流水显示相同图标。分类改名后会重新匹配。

新建默认选中首个支出分类和首个支付渠道。再点已选渠道可取消，仅影响本笔。时间默认为打开录入页时的当前时间。金额下方可直接补充事项和商户，事项留空时用分类名。

保存按钮固定在键盘上方，保存中禁止重复提交。返回键、手势和页面返回使用相同逻辑；有未保存修改时先确认，配置变化保留表单。保存后保留原搜索、筛选及列表位置；记录被筛选隐藏时提示。

账本可导出加密备份并恢复。0.4 移除了截图识别及图片分享入口，历史已入账流水仍可查看和编辑。旧版草稿和附件仅用于备份兼容。

## 工程与验证

KMP + CMP + Room；Android SDK 36，JDK 17，Gradle 8.11.1。iOS 宿主后续开发。

首次构建时安装 JDK 17、Android SDK Platform 36 和 Build Tools 35.0.0。通过 `ANDROID_HOME` 环境变量或本机 `local.properties` 的 `sdk.dir` 指定 SDK，使用仓库内的 Gradle Wrapper 构建。

```powershell
.\gradlew.bat :sharedCore:jvmTest :androidApp:testDebugUnitTest :androidApp:assembleDebug :androidApp:lintDebug
```

APK：`androidApp/build/outputs/apk/debug/androidApp-debug.apk`，开发签名，覆盖安装需保持相同签名。

旧版验证记录：[docs/verification.md](docs/verification.md)。
